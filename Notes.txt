1. Software development lifecycle (Waterfall model)
   a. Requirement Gathering
   b. Desing 
   c. Development
   d. Testing
   e. Development
   f. Maintainance

--> Requirement Gathering:
   1. Create an account
   2. Login
   3. update Your profile
   4. Feed page - explore
   5. Send Connection Request
   6. See our matches
   7. See the Request we've sent/receive
   8. Update your profile

--> DB Design :
   --User :- First name, mid name, last name, email, password, age, gender.
   --ConnectionRequest :- FromUID, ToUID, status {pending, reject, accept, ignored}

--> API:
   POST   /signup           -User Registration
   POST   /Login            -User Authentication
   GET    /profile          -Get the profile
   POST   /profile          -POST the profile 
   PATCH  /profile          -Update the profile
   DELETE /profile          -DELETE profile
   POST   /SendRequest      -Ignore, interested
   POST   /reviewRequest    -accept, reject
   GET    /requests         -View the pending requests 
   GET    /Connection       - See all the connections

--> Creating the server
   1. npm init
   2. node app.js
   3. npm i express
   4. Create a server
   5. Listen at a port
   6. Write requset handlers
   7. install nodemon, and update the package.json
